# Mind Gym (마음의 헬스장)
**대인관계 회복을 위한 AI 롤플레잉 코치**

Mind Gym은 단순히 공감하거나 위로하는 챗봇이 아니라,  
사용자가 실제 사회적 상황에서 **어떻게 말해야 하는지**를 훈련하는  
**행동 교정 중심 AI 롤플레잉 코치**입니다.

현대의 많은 사용자들은 감정의 문제가 아니라,  
관계 속에서 필요한 **말하기 기술과 대응 전략**을 잃어버렸습니다.  
Mind Gym은 이를 “연습 가능한 기술”로 보고,  
반복 훈련과 즉각적인 개입을 통해 **실제 행동 변화를 유도**하는 것을 목표로 합니다.

---

## Core Concept

### 🎯 행동 교정 중심 AI
- “힘들었겠네요”에 머무르지 않음
- “다음엔 이렇게 말해보세요”처럼 **구체적인 문장과 전략 제시**
- 실전 상황에서 바로 써먹을 수 있는 말하기 훈련 제공

### 🎭 롤플레잉 기반 훈련
- 화난 상사, 무뚝뚝한 점원, 까칠한 상대 등  
  현실적인 **페르소나(persona)** 와의 대화
- 사용자는 안전한 환경에서 반복 연습 가능

### 🧠 2:1 멀티 에이전트 구조
- **사용자 vs 페르소나(상대역)**
- **코치(Coach)** 가 옆에서 개입하여 방향 제시
- 필요 시 **Supervisor**가 품질을 점검하고 재실행 판단

### 📈 단계적 노출(Level System)
- 난이도 조절을 통한 점진적 훈련
  - Level 1: 친절한 상대
  - Level 2: 무뚝뚝한 상대
  - Level 3: 화난 상사
- 사회적 불안, 콜 포비아 상황을 단계적으로 극복하도록 설계

## What This Repository Is

이 저장소는 **Mind Gym 전체 시스템의 통합 레포지토리**입니다.  
각 브랜치는 역할별로 명확히 분리되어 있습니다.

```
main : 프로젝트 전체 개요 및 문서
ai : AI 모델·프롬프트·코치/슈퍼바이저 로직
backend : API 서버, 세션 관리, 상태 저장
frontend : 사용자 인터페이스 (웹/앱)
feedback : 피드백 고도화 및 실험 브랜치
```

- `main` 브랜치는 **아키텍처와 철학을 설명하는 문서 중심 브랜치**입니다.
- 실제 구현 코드는 각 역할별 브랜치에서 관리됩니다.

## High-Level Architecture

```
User
↓
Frontend
↓
Backend API
↓
┌───────────────────────────────┐
│ Conversation Graph │
│ │
│ Persona (상대역) │
│ ↑ │
│ Coach (행동 교정 개입) │
│ ↑ │
│ Supervisor (품질 검증/재실행) │
└───────────────────────────────┘
↓
Feedback (사후 요약 및 학습 가이드)
```
- Redis 기반 세션 상태 유지
- 멀티턴 대화 및 서버 재시작 후 복원 지원
- 실시간 개입 + 사후 피드백의 이중 구조
